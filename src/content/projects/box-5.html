Project Overview

I built an 8-key musical keyboard on an Arduino Uno — designed the circuit, worked out the math behind it, and prototyped the electronics myself. To read all eight buttons through one analog input, I designed and built an analog resistor ladder (voltage divider).

Instead of burning eight digital pins polling each button separately, the resistor ladder feeds a different voltage into a single analog pin (A0) depending on which key's pressed. The Arduino reads that voltage in real time and maps each range to its own frequency on a piezo buzzer.

int redPin = 11, greenPin = 10, bluePin = 9;
int button1 = 5, button2 = 4, button3 = 3;

void setup(){
  pinMode(redPin,OUTPUT); pinMode(greenPin,OUTPUT); pinMode(bluePin,OUTPUT);

  if(digitalRead(button3) == LOW){ redValue=255; greenValue=0;   blueValue=255; } // magenta
  delay(10);
}

Summary: Wired an RGB LED with one leg to voltage and the other three to red/green/blue pins. Three buttons each mix a different color: yellow, cyan, magenta.

Direct precursor to the resistor-ladder keyboard below.

Tutorial 4's voltage-divider math — splitting 5V across paired resistors and checking the result against analogRead() — is exactly the technique scaled up below into an 8-key resistor ladder on a single analog pin.

Core Prototyping Achievements

  • Mathematical Voltage Scaling: Calculated optimal resistor values to split the 5V reference into eight distinct, highly spaced voltage brackets. This guarantees noise immunity and eliminates incorrect note triggering due to resistor tolerance margins.
  • 1-Pin Analog Keypad Decoder: Programmed a high-performance Arduino loop utilizing customized logic brackets to map analog values (0 to 1023 resolution) to specific musical note frequencies.
  • Piezo Buzzer Integration: Designed a debounce-free hardware trigger circuit which immediately cuts off tones ('noTone(8)') when no buttons are closed, providing crisp, clean acoustic output.

Source Code (Arduino C++)

synthesizer.ino Arduino IDE

int note[] = {100, 200, 300, 400, 500, 600, 700, 800};


void setup() {

Serial.begin(9600);

}


void loop() {

// Variable to hold the value read on pin A0

int keyVal = analogRead(A0);

Serial.println(keyVal);


// Play the note matching with the analog value

if (keyVal >= 1023) {

tone(8, note[0]);

} else if (keyVal >= 1 && keyVal <= 127) {

tone(8, note[1]);

} else if (keyVal >= 128 && keyVal <= 256) {

tone(8, note[2]);

} else if (keyVal >= 257 && keyVal <= 385) {

tone(8, note[3]);

} else if (keyVal >= 386 && keyVal <= 514) {

tone(8, note[4]);

} else if (keyVal >= 515 && keyVal <= 643) {

tone(8, note[5]);

} else if (keyVal >= 644 && keyVal <= 772) {

tone(8, note[6]);

} else if (keyVal >= 773 && keyVal <= 1022) {

tone(8, note[7]);

} else {

// Stop playing when no buttons are pressed

noTone(8);

}

}
